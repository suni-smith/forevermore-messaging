Privacy Policy

Hermes Personal Assistant · Last updated 30 August 2026

What this application is

Hermes is a personal, self-hosted assistant run by a single individual on hardware he owns. It is not a commercial product and has no users other than its operator. It reads his own Google Calendar so it can remind him of upcoming events.

What data is accessed

The application requests one Google OAuth scope: https://www.googleapis.com/auth/calendar.events.readonly. This grants read-only access to calendar events. The application cannot create, modify, or delete calendar entries, and does not request any other Google data.

Data accessed consists of event titles and start times for events in the near future, used to generate a reminder.

How the data is used

Calendar event data is read at the moment a reminder is generated and used only to compose that reminder for the account owner. It is not used for advertising, profiling, analytics, training machine-learning models, or any purpose other than reminding the owner of his own appointments.

Limited use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

OAuth tokens are stored on the owner's own machine with file permissions restricted to his user account. Calendar event data is not written to any database and is not retained after a reminder is produced. Nothing is stored on any third-party server operated by this application.

Sharing

No data is sold, rented, shared with third parties, or transferred to anyone. There are no third-party analytics, advertising, or tracking components.

Revoking access

The account owner can revoke this application's access at any time at myaccount.google.com/permissions, which immediately invalidates its tokens. He may also delete the stored token file from his own machine.
