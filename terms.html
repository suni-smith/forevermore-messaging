Forevermore Messaging Program · Last updated 30 August 2026

Program name

Forevermore — a personal system-notification SMS program.

Program description

Forevermore sends automated operational alerts by SMS to a single recipient: the sole proprietor who operates the system, on a mobile number he owns. Typical messages report that a background service has stopped responding, or that a calendar event is approaching. There is no marketing content, no promotional content, and no other recipient.

How consent is obtained

The recipient is the account owner. He consented by entering his own mobile number into the configuration of software running on hardware he owns. There is no public sign-up and no subscriber list.

Message frequency

Message frequency varies and depends on system events. In normal operation the program sends few or no messages; alerts are generated only when a monitored condition occurs.

Message and data rates

Message and data rates may apply. Charges are set by the recipient's mobile carrier.

Opt-out instructions

Text STOP to any message to cancel. After texting STOP, no further messages will be sent. The recipient may also stop messages by removing the number from the system configuration.
